# 🎬 KinoMap

A simple and visual way to explore, organize, and discover movies.

KinoMap is a personal movie project focused on making film discovery more intuitive through a clean and cinematic interface.

## ✨ Features

* 🎞️ Browse and explore movies
* ⭐ Organize films based on ratings and information
* 🔎 Search and discover titles easily
* 🗺️ A visual interface designed around the idea of a "map" of cinema

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* Movie data: IMDb datasets
* API / AI integrations: Groq

## 🚀 Project Status

KinoMap is currently under development.
